Replies
When a message is just a number, the bot replies “this is the number you typed: …” with that number. Turn on Number facts to get facts about it instead (prime, binary, Roman numerals…).
Keyword rules
One rule per line: keyword => reply. Use || to send several bubbles, {text} for the message and {time} for the current time. Rules are checked top to bottom, before number facts.
